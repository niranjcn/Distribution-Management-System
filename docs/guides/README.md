# User Role Guides — Distribution Management System

This documentation explains how to use the DMS website, function by function, for each
user role. Each guide assumes you have read **[getting-started.md](getting-started.md)** first,
which covers login, the shared interface, notifications, and your profile.

## Your role guide

| Role | What they mainly do | Guide |
|------|--------------------|-------|
| **Super Admin** | Full control: users, devices, distribution, approvals, reports, backups, audit | [super-admin.md](super-admin.md) |
| **MD / Director** | Executive oversight, reports, activity audit, read-only access | [md-director.md](md-director.md) |
| **Manager** | Manage users, devices, distributions, approve workflows, reports | [manager.md](manager.md) |
| **PDIC Staff** | Register and manage devices, distributions, defects, external inventory | [pdic-staff.md](pdic-staff.md) |
| **Sub Distribution MD / Manager** | Manage sub-distribution team, approve field requests, scoped reports | [sub-distribution-manager.md](sub-distribution-manager.md) |
| **Sub Distributor** | Run distribution in the field, confirm deliveries, approve sub requests | [sub-distributor.md](sub-distributor.md) |
| **Cluster** | Field distribution, deliveries, defect reporting, returns | [cluster.md](cluster.md) |
| **Operator** | Personal device and distribution work, defect reports, confirmations | [operator.md](operator.md) |
| **Sub Distribution Employee** | Field work, delivery confirmations, submit approval requests | [sub-distribution-employee.md](sub-distribution-employee.md) |

## How the guides are written

- **"You can see"** — pages and actions available to that role.
- Step-by-step instructions assume you are already logged in (see Getting Started).
- Every feature in a guide maps to a real page or button in the application.

## If you cannot find what you need

- Check you are using the correct guide for your role.
- Check the **Notifications** page — many actions require a notification to reach you first.
- Contact your administrator if a feature listed as "available" is missing from your menu.
